# C Programming Problems

## 📖 About
This repository contains my collection of C programming problems with solutions. It covers topics like:
- Basics and Operators
- Control Flow (if-else, switch)
- Loops (for, while, do-while)
- Functions
- Arrays & Strings
- Pointers
- Structures
- File Handling

## 💡 Purpose
To organize and share my C programming practice problems for easy reference and revision.

## 🚀 How to Use
- Clone the repository
- Compile the `.c` files using GCC or any C compiler
- Run and explore the outputs
