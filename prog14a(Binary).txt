Binary   Integer
--------------------
1) What  is  the  prefix  of  binary  number ? --->  0B  (or)  0b

2) Which  digits  are  permitted  in  binary  number ? --->  0  and  1

3) What  is  the  base  of  binary  number ?  --->  2  due  to  two  digits  0  to  1

4) Which  digits  are  not  permitted  in  binary  number ?  --->  2  to  9

5) What  is  the  format  of  binary  number ? --->  No  format

6) Which  of  the  following  are  valid  binary  numbers ?
     a) 0B10201  --->  Error  due  to   2
     b) 0B1010101  --->  Valid
     c) 010101  --->  Invalid  becoz  there  is  no  prefix  0B
     d) 0X10101  --->  Invalid  becoz  there  is  no  prefix  0B
     e) 10101 --->   Invalid  becoz  there  is  no  prefix  0B

7) binary  int  x  = 0B10101 
     Is  the  above  statement  valid ?  --->  No  becoz  there  is  no  binary  keyword
